Scripted native UI with fictional records and injected website metadata. No audio. This demonstrates interface workflows, not OS integration or encryption verification.

- 00:00:29: **More context for your text.** Readable JSON, code, email, and phone previews. Original text stays intact.
- 00:00:32: **Make it fit your day.** Set your shortcut, pause capture, and manage privacy preferences.
