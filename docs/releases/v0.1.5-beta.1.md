# CopySaver 0.1.5 Beta 1

First community beta for macOS. This is an early-access release for testing, not a stable release or a password manager.

## Download and install

Download **CopySaver-0.1.5-beta.1-universal.dmg** from this release. It contains Apple silicon and Intel builds targeting macOS 14 or later. Local runtime validation has been on Apple silicon; minimum-macOS and Intel execution remain unverified.

1. Quit an existing CopySaver instance.
2. Open the DMG, drag CopySaver into Applications, and replace the existing copy when updating.
3. Open CopySaver from Applications. This community build is ad-hoc signed, without an Apple Developer ID certificate or notarization. macOS may block it; if you trust the source, follow Apple's [Open Anyway instructions](https://support.apple.com/en-us/102445) in Privacy & Security. Managed Macs may prohibit this. Updates may prompt again. Do not disable Gatekeeper or remove quarantine.
4. Where macOS asks for clipboard access, allow it for CopySaver. Capture keeps new copies; it does not import the current clipboard.
5. Open Focus mode with **Option-Command-V**, select text, then press Return to copy. Paste with Command-V in the destination app. Change the shortcut in Settings.

To verify the downloaded files, put the release assets together and run `shasum -a 256 -c SHA256SUMS`. Checksums detect a mismatched download; obtain them from the same trusted release. `RELEASE_MANIFEST.json` identifies the exact source and artifact hashes.

## Included

- Local clipboard history with search, pinning, retention, pause and resume.
- Named snippets, optional concealed previews, and exact original-text copying.
- Full Library and globally accessible Focus panel.
- Automatic website title, description and thumbnail previews for the selected non-sensitive HTTPS link. Disable in Settings → Privacy & Storage.
- Local email/phone presentations and JSON/code preview/original views.
- Layered C app icon and refined native light/dark interface.
- Universal ad-hoc app, App Sandbox, hardened runtime and encrypted SQLite payloads. No Apple account is needed to use or build the community app.

## Privacy and recovery

Saved payloads are encrypted with AES-256-GCM. The random key is separate in the macOS login Keychain. Copied database files alone do not reveal saved text; an unlocked/compromised account or decryptable Keychain is outside this protection. Sensitive conceals previews and body search; it does not require extra authentication inside an open community library.

Website previews contact the page and its image host, revealing your IP and requested URL. They use no cookies, credentials or persistent app cache. Core capture/search/copy/storage works offline. No telemetry, account, cloud sync or automatic update polling.

There is **no portable backup or recovery**. Keep another copy of important information. Losing the Keychain key can make saved data unrecoverable. Previous protected builds use a separate library and are not migrated. Community updates retain the same identity and storage format; older clients that rewrite settings can discard the new preview-disable preference.

## Validation and known limits

The release source is checked with `make verify`; the release package is checked for app/widget versions, both architectures, ad-hoc signatures, sandbox/hardened runtime, exact icon, entitlements, checksums, DMG integrity and mounted installer layout. Source revision, actual toolchain and dependency inventory are attached. No third-party runtime packages are used. These checks do not establish a clean-Mac or independent security review.

Remaining acceptance: downloaded/quarantined clean-Mac installation and upgrades, minimum-OS and Intel execution, complete OS permission/sleep/session behavior, native shortcut/Spaces cases, VoiceOver, runtime network observation and widget gallery discovery. The widget is bundled as experimental generic navigation; discovery in ad-hoc builds is unverified. Hosted CI status must be checked separately; local checks do not stand in for a green hosted run.

Report reproducible problems through Issues using synthetic text. Do not attach saved libraries, private clipboard content, credentials or Keychain files. Follow [SECURITY.md](https://github.com/rafsuntaskin/copysaver/blob/main/SECURITY.md) for private vulnerability reporting.
