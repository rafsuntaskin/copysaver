# Changelog

## 0.1.5 Beta 1 (8) · community release candidate · November 12, 2026

- Prepare the first versioned community beta for GitHub, preserving the existing library identity and storage format.
- Add installer/update/troubleshooting guides, safe bug reporting and explicit privacy/recovery disclosures.
- Add audited distribution manifests, checksums, exact source archives and draft-only release automation.
- Retain the Layered C icon, automatic capture, local content views and automatic selected-link website previews from the tested previews.

Stable native/security/accessibility/clean-Mac gates remain pending; this is a beta, without Apple Developer ID signing or notarization.

## 0.1.4 (7) · local development preview · November 12, 2026

- Load real website titles, descriptions and thumbnails automatically for the selected non-sensitive HTTPS link.
- Add an encrypted preview-disable preference in Privacy & Storage, bounded memory-only networking, cancellation guards and retry states.
- Keep sensitive snippets out of network requests and preserve exact text copying.

## 0.1.3 (6) · local development preview · November 12, 2026

- Adopt the approved graphite, cobalt and silver Layered C app icon.
- Recognize web links, email addresses, phone numbers, JSON and code in History and Snippets, with shared type cues in Focus.
- Add offline link/contact previews and JSON/code preview/original views; keep the Copy button faithful to saved text.
- Keep sensitive bodies concealed and unclassified, with no automatic network requests or storage migration.

## 0.1.2 (5) · local development preview · November 11, 2026

- Clear the Focus mode launcher’s stored focus when opening or closing the panel.
- Draw sidebar keyboard outlines only in the actual key window, preserving keyboard focus feedback and navigation selection.

## 0.1.1 (4) · local development preview · November 11, 2026

- Bump the app and launcher widget together so this installer is distinguishable from the earlier 0.1.0 previews.
- Preserve the community bundle identity and encrypted storage format; no data migration is introduced.
- Document retiring duplicate development builds while preserving their app archives, stored libraries and Keychain keys.

This patch retains the UI and capture behavior of 0.1.0 build 3. Native release acceptance remains tracked in spec.md; this entry does not announce a tagged or notarized release.
